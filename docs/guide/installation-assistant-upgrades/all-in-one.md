# All in one

Upgrade is not supported by the Wazuh installation assistant. For upgrade instructions, refer to the documentation at [step-by-step upgrades](../step-by-step-upgrades/all-in-one.md).

Those steps upgrade between 5.x versions. To move a 4.x deployment installed with the Wazuh installation assistant to 5.0, see [Migration from 4.x](../migration/all-in-one.md).
